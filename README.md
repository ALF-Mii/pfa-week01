# pfa-week01
A1 — Environment + first tool

## Tool

| Script | What it does |
| --- | --- |
| Stair Generator | Builds straight or circular staircases from sliders for step count and height. |

## How To Run

1. Open Maya.
2. Open the **Script Editor** and switch to the **Python** tab.
3. Make sure this folder is on Maya's Python path, or paste the script contents directly.
4. Run
